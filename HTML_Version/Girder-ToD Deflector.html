Girder and Top of Deck Deflected points

Download the Data Sheet template, fill in your data, upload the file and calculate girder and deck points.
Optionally, upload a FG DTM XML surface file to project the girder points and add deflections.

The Calculator tab performs all calculations and exports. The Girder Profile Graph tab displays the girder deflection profile graph.
